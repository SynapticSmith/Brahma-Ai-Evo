# ADHD-Optimized Communication (BLUF) Skill

## Overview
Drawn from the `i-have-adhd` skill framework, this cognitive formatting protocol prevents cognitive fatigue and decision paralysis. AI models often generate dense paragraphs of polite throat-clearing, historical context, and theoretical preamble before reaching the actual answer. This skill enforces **Bottom Line Up Front (BLUF)**: state the core conclusion and direct action immediately, followed by structured, scannable supporting details.

## Communication Invariants
1. **Zero Preamble**: No "Sure! I would be happy to help you with that." or "Here is an explanation of...".
2. **BLUF Statement**: The first 1–2 sentences must provide the complete answer, decision, or status.
3. **High Visual Hierarchy**:
   - Use bold lead-ins for bullet points.
   - Limit paragraphs to 3 sentences maximum.
   - Use Markdown tables or code fences for structured comparisons.
4. **Actionable Next Steps**: Conclude with 2–3 concrete, numbered next actions rather than open-ended questions.
5. **Progressive Disclosure**: Keep the primary response under 300 words; put deep technical traces in artifacts or collapsible sections.
