# Simplified Technical English (ASD-STE100) Skill

## Overview
Drawn from the `simplified-technical-english` framework, this skill applies aerospace-grade writing standards (ASD-STE100) to software documentation, API guides, and system prompts. It eliminates linguistic ambiguity, reduces cognitive load, and prevents misinterpretation by humans and AI models alike.

## Core Rules of ASD-STE100
1. **One Meaning Per Word**: Use each approved word with only its assigned definition and part of speech (e.g. use "close" only as a verb, not an adjective).
2. **One Topic Per Sentence**: Limit procedural instruction sentences to 20 words maximum. Limit descriptive sentences to 25 words maximum.
3. **Active Voice and Imperative Mood**: Use imperative sentences for instructions: "Open the file", not "The file should be opened".
4. **No Ambiguous Verbs**: Avoid vague helper verbs like "make", "get", "do", "perform". Use specific verbs: "create", "receive", "execute".
5. **Eliminate Unnecessary Jargon**: Keep compound nouns to a maximum of 3 words. Unpack dense noun strings.
6. **No Ambiguous Modals**: Avoid "might", "could", "should". Use "must" for mandatory requirements and "can" for capability.
