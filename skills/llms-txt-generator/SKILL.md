# LLMs.txt Generator Skill

## Overview
Drawn from `automatic-ai-experiments`, this skill compiles standardized `llms.txt` and `llms-full.txt` documentation manifests. The `/llms.txt` standard provides small and large language models with a curated, machine-friendly index of documentation links, architecture summaries, and API endpoints, eliminating bloated context consumption and web scraping hallucinations.

## Specification Standard
An `llms.txt` file is clean Markdown adhering to:
1. **H1 Title**: Project name and one-line mission.
2. **Blockquote**: Canonical project summary and key invariants.
3. **Core Documentation Links**: Markdown bullet lists of primary guides (`[Title](path.md): summary`).
4. **Optional Section**: Secondary guides, architectural specs, and examples.
5. **Full Manifest (`llms-full.txt`)**: Bundles concatenated full markdown text of all core pages for offline model context injection.

## Invariant Rules
1. **Relative & Canonical URLs**: All markdown links must resolve cleanly to public URLs or repository-relative paths.
2. **Concise Descriptions**: Link annotations must be single-sentence summaries describing the scope.
3. **Automated Freshness**: Regenerate `llms.txt` whenever documentation files or architecture specs are added or renamed.
4. **No Binary or Slop Ingestion**: Exclude autogenerated API docs, bundle maps, or build output.
