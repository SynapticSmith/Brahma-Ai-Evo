# Cookbook: Headless Office Document Processing

## Objective
Read, modify, or generate Word, Excel, and PowerPoint documents programmatically using lightweight Python tooling.

## Prerequisites
- Python 3.11+ environment with `openpyxl`, `python-docx`, or `python-pptx` (installed in optional dependencies).

## Execution Recipe
1. **Extract Structured Data from Excel (`.xlsx`)**:
   ```python
   import openpyxl
   wb = openpyxl.load_workbook("data.xlsx", data_only=True)
   sheet = wb.active
   rows = [[cell.value for cell in row] for row in sheet.iter_rows()]
   ```
2. **Generate Styled Word Report (`.docx`)**:
   ```python
   from docx import Document
   doc = Document()
   doc.add_heading("Operational Summary", level=1)
   doc.add_paragraph("Automated summary generated by Brahma AI harness.")
   table = doc.add_table(rows=1, cols=3)
   doc.save("output_report.docx")
   ```
3. **Inspect Slides and Notes in PowerPoint (`.pptx`)**:
   ```python
   from pptx import Presentation
   prs = Presentation("deck.pptx")
   for idx, slide in enumerate(prs.slides):
       notes = slide.notes_slide.notes_text_frame.text if slide.has_notes_slide else ""
   ```
4. **Verification Gate**:
   Verify that generated files open without XML corruption warnings:
   - File size > 0 bytes.
   - ZIP container structure valid (`python -m zipfile -t <file>`).
5. **Remediation**:
   If a library is missing, fall back to converting documents to Markdown/CSV via `tools/ingest_multimodal.py`.
