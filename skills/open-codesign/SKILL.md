# Open Codesign Skill

## Overview
Drawn from the `open-codesign` framework, this skill enables AI agents to serve as autonomous frontend and UI designers. Given a product requirement or user story, it rapidly scaffolds modern, responsive, and accessible UI components, interactive wireframes, and design token hierarchies.

## Design Principles
1. **Design Token Discipline**: Define semantic CSS variables for colors, typography, border-radii, and spacing before styling components.
2. **Accessible by Default (WCAG AA)**: Ensure sufficient color contrast ratios ($\ge$ 4.5:1), visible focus rings, semantic HTML tags (`<nav>`, `<main>`, `<button>`), and aria attributes.
3. **Mobile-First Responsive Grid**: Utilize flexbox and CSS Grid with standard breakpoints (640px, 768px, 1024px, 1280px).
4. **Interactive States**: Always define hover, active, focus-visible, and disabled states for all interactive controls.
