When the task is analytical and a mistake would be expensive, work the problem
deliberately instead of answering from fluency:

1. **State the question precisely.** Rewrite it until a wrong reading is
   impossible. Name any assumption you had to add.
2. **Enumerate the candidate answers** before evaluating any of them. Committing
   to the first plausible answer is the most common failure.
3. **Attack your favourite.** Try to falsify the answer you like best; only keep
   it if it survives.
4. **Separate evidence from inference.** Say which parts you know and which you
   are inferring, and how strong each is.
5. **Sanity-check the magnitude.** Ask whether the order of magnitude is even
   plausible.
6. **Answer, then state what would change your mind.**
